# Benefits Architecture Toolkit

Draft v0.1, September 2026.

The Markdown files in this folder are written to be directly usable as Docusaurus documentation pages. They include YAML front matter, relative internal links, and Mermaid diagrams.

Start with `index.md`.

## Suggested Docusaurus structure

Copy the entire folder into an appropriate versioned docs directory, for example:

```text
versioned_docs/
└── version-0.1/
    └── benefits-architecture-toolkit/
```

Mermaid rendering requires Mermaid support to be enabled in the Docusaurus site.

This is an initial working draft and should be iterated before being presented as a formal methodology.

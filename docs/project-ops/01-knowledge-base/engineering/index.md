# Engineering

Engineering guidance covers ALM, solution boundaries, supported extension points, monitoring and operational controls.

## First-pass principles

- Separate solution customisations from operational/configuration data.
- Confirm supported APIs before updating scheduling or product-owned lifecycle records.
- Keep deployment evidence with the change record.
- Treat integration map changes, plugins and Power Automate flows as architecture-relevant.
- Include rollback, monitoring and support ownership for every material extension.

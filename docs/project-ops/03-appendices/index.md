# Appendices

Appendices hold reusable artefacts. Each artefact should explain when to use it, intended audience, required fields, evidence standards and expected output.

## Priority artefacts

| ID | Artefact | First format |
| --- | --- | --- |
| T-001 | Stakeholder interview / discovery questionnaire | Markdown |
| T-002 | Deployment-model selection worksheet | Markdown |
| T-005 | Architecture decision record | Markdown |
| T-011 | Audit evidence register | CSV / Markdown |
| T-012 | Findings and risk register | Markdown |
| T-015 | End-to-end test scenario and evidence record | Markdown |

:::warning[No client data]

Templates and examples must avoid real client records or identifiable company data unless explicitly sanitised and approved for reuse.

:::

# Project Operations Knowledge Base

Internal knowledge base for Microsoft Dynamics 365 Project Operations.

Use it as a working consulting toolkit:

- [Start here](./00-start-here/index.md) explains how to use and maintain this area.
- [Knowledge base](./01-knowledge-base/architecture/index.md) contains reusable product and architecture reference material.
- [Engagement playbooks](./02-engagement-playbooks/index.md) apply the reference material to new implementations, assessments and onboarding work.
- [Appendices](./03-appendices/index.md) hold reusable templates, checklists and reference matrices.
- [Tooling interface](./04-tooling-interface/index.md) records desired outputs for related automation without documenting CLI implementation details.

:::warning[Internal-first material]

Do not treat this subsection as client-ready documentation. Client material should be selected, validated, redacted and adapted into a separate deliverable.

:::

The [charter](./project-operations-knowledge-base-charter.md) remains the planning baseline while this foundation is being built out.
